# Screening run sheet (family events, launches, rooms with a projector or TV)

## Device test (2-5 days before, same room if possible)

- [ ] The exact file plays on the exact device (projector's own player, TV USB, laptop) start to finish
- [ ] Image fills the wall after keystone/zoom; check that the 86 % safe area is fully visible
- [ ] Text readable from the back row; faces not too dark (lift the grade or use a brighter room setting)
- [ ] Audio: external speaker connected, level set with the room's noise; no hum (ground loop: use the laptop on
      battery); the narration is clear at the back
- [ ] Laptop: sleep, screen saver, notifications, auto-updates off; player set to no looping, no subtitles
- [ ] 720p backup plays too; a phone copy for emergencies

## Files to carry

| File | Where |
|---|---|
| Master (projector preset) | laptop + pen drive (exFAT/NTFS if > 4 GB) |
| 720p backup | pen drive + phone |
| Any loop for before/after (photos, a cake loop) | only if the client asked for one |

## What goes wrong in the room

- Projector's player stutters on high bitrates: switch to the 720p backup or the laptop.
- Audio out of sync over Bluetooth speakers: use a cable.
- Children talk over quiet scenes: that is fine; questions in the film wait 6-8 s for them.
- Someone asks to pause and explain: let them; the film resumes on the same frame.
