# Voice casting and audition

## Casting brief (write it before listening to anything)

```
Who:       <gender, age range>, <region / city>, <occupation that sets the register: retired headmaster, young
           science teacher, radio host>
Sound:     <deep warm baritone with a little gravel | bright, quick, smiling>
Pace:      <unhurried, long natural pauses | brisk>
Register:  <educated city dialect; English words said the way the city says them>
Attitude:  <dry and affectionate; you hear the smile; never gushes>
Mic:       <close, like telling a story to a child on a winter evening | studio-clean>
Rules:     <never describes the screen; third person; silence after emotional lines>
Avoid:     <announcer voice, sing-song, over-acting, a celebrity imitation>
```

## audition.json

```json
{
  "lines": ["1A", "4C", "6D", "7Da", "9H", "13A"],
  "name_tests": ["<hero name spelling 1>", "<spelling 2>", "<spelling 3>"],
  "candidates": [
    {"name": "voice A", "provider": "sarvam", "voice": "<speaker>", "lang": "bn-IN"},
    {"name": "voice B", "provider": "sarvam", "voice": "<speaker>", "lang": "bn-IN"},
    {"name": "multilingual", "provider": "elevenlabs", "voice": "<voice_id>"}
  ]
}
```
Lines may also be inline objects `{"id": "x", "text": "...", "dir": "..."}`. The page groups takes by line so the
client compares voices on the same words. Put a one-line note per candidate on the page ("rich, cinematic; might
be too grand").

## Provider notes (verify current docs and prices before use; APIs and models change)

| Provider | Strength | Watch out |
|---|---|---|
| Sarvam (bulbul) | Indian languages, many speakers, pace control; commercial use allowed per its terms | clone voices use a separate endpoint; only the owner may clone their voice |
| Sarvam (saarika STT) | verification of Indian-language lines | numerals and names may transcribe differently: compare after normalising |
| ElevenLabs | expressive English and multilingual, voice design | Indian-language pronunciation varies; check commercial plan terms |
| OpenAI speech | instructions per line (delivery direction), cheap | limited Indian-language naturalness; voices are fixed |
| Recorded human | authenticity | needs a quiet room and line-by-line takes; edit breaths, not words |

Keys live in env vars or the key file named in config.json (`SARVAM_API_KEY`, `ELEVENLABS_API_KEY`,
`OPENAI_API_KEY`); `python tools/keys.py NAME` checks presence without printing.

## Respell examples (film/respell.json)

```json
{
  "_note": "caption spelling -> what the engine should read; keys starting with _ are ignored",
  "<name with a joiner>": "<same name without the joiner>",
  "café": "kafe",
  "2026": "twenty twenty-six",
  "Dr.": "Doctor",
  "ASCI": "A S C I"
}
```
Test the hero's name first, in three spellings, in the audition. Keep captions in the correct spelling always.

## Recording real voices (the client, family, talent)

Quiet room, soft furnishings, fan and AC off, phone 20-30 cm from the mouth, slightly off-axis. Read each line
twice. Name files by line id (`7Da_take2.m4a`; anything after `_` or `-` is ignored), then:

```bash
python tools/voice/import_vo.py inbox/05_voice-notes/ [--verify]    # trim, -18 LUFS, measure, mark "recorded"
python film/timeline.py
```
Recorded lines are never regenerated by `gen_vo.py` (not even with `--all`) unless their id is named
explicitly, so a mix of recorded and synthetic lines is safe.
